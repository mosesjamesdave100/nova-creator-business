NOVA — VISUAL DESIGN DIRECTION

Design system & homepage direction

A dark, editorial system for a multi-platform creator business — built to hold Section 01 (Hero) and 02 (What's Happening Now) now, and scale to Content, Shop, Community and beyond. This is a direction to approve, not the built site.

BEFORE YOU APPROVE — FOUR CALLS I MADE
Accent needs a second job

#C7FF3D reads clearly as "live/active," which competes with the LIVE dot everywhere. I've reserved pure lime strictly for the live state + primary CTA, and moved secondary emphasis (view counts, selected nav) to a dimmer lime tint so the eye still knows what's actually live.

Two floating hero widgets is a lot

Live status + a product drop both floating over one photo risks clutter exactly where the brief warns against it. I've kept the drop card small, lower-contrast and lower in the frame, clearly secondary to the live card.

Ecosystem strip needs a disclaimer, not just restraint

Follower counts sitting in the footer of a hero read as real metrics even when small. I've added a tiny "demo figures" label so the portfolio piece can't be mistaken for a real audience claim.

Section 02 should sell one action, not four

Featured video + live panel + next-up + activity row all in one section dilutes the CTA. I've made the featured video / live panel the unmistakable hero of the section and demoted "next up" and "latest" to a quieter supporting strip — content discovery without four competing asks.

03 — SPACING, RADIUS & MOTION

Editorial restraint, not decoration

Spacing
  • 8px base unit; section rhythm at 96–160px
  • Generous negative space around the hero headline
  • Cards breathe — 24–32px internal padding, never tight
Radius
  • 4px on buttons, tags, inputs — quiet, not pill-shaped
  • 8–12px on cards and floating panels
  • Photography stays rectangular or intentionally cropped, never rounded
Motion
  • Entrance sequence ~1s total, staggered ~80–120ms per element
  • Parallax on hero photo capped at 6–8px
  • Live dot pulses on a slow 2s cycle — utility, not decoration
  • Hover scale 1.02 max; no glow, no particles, no 3D tilt

09 — RESPONSIVE RULES

Rebuilt for mobile, not shrunk

  • Hero: split-screen becomes stacked — copy first, image second, floating widgets flatten into the image or drop below it.
  • Nav: full link row collapses to NOVA + MENU; live dot moves into the menu sheet, not the bar.
  • Section 02: featured video → live/next-stream state → next up → latest activity, single column, full-width cards.
  • Ecosystem strip: four platforms in a tight 2×2 grid rather than one row.
  • Touch targets: all CTAs ≥44px tall; no hover-only affordances.
